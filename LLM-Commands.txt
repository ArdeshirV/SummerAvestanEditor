Build and maintain **Avestan Editor**, a cross-platform Unicode text editor.

1. Use Qt Widgets and C++17. Support Linux, Windows, and Android. Follow existing project/build conventions; embed app data and resources with Qt resources.
2. Use `QPlainTextEdit` for native typing, caret, selection, clipboard, undo/redo, touch, and mobile keyboard behavior. Wrap long lines; scroll vertically; never implement a custom caret or mouse editor.
3. Support UTF-8 (with/without BOM), UTF-16 LE/BE, and BOM-marked UTF-32 LE/BE. Reject malformed input. Preserve a file's detected encoding when saving. Make Save As confirm overwrites. Route close/exit through Yes (save), No (discard), Cancel (stay).
4. Shortcuts: Ctrl+O open, Ctrl+S save, Ctrl+Shift+S Save As, Ctrl+Shift+U insert Unicode code point, F1 About, Ctrl+X exit through unsaved-changes handling.
5. Top bar: Open, Save, Save As, Settings, About, Exit (far right). Put the Language label and selector above the editor/keyboard splitter. On the same Language row, after the selector, put Insert U+…, Hide/Show keyboard, then Right to left at the row's end. Persist RTL state; align paragraphs right/left without changing layout or keyboard direction.
6. Order languages: Avesta, Pahlavi, Parthian, Ancient Persian; then other ancient Iranian/historic scripts, other Unicode scripts/languages, symbols, and All printable Unicode. Use Qt's Unicode tables. Show language samples where available. List every printable character and virtualize large lists.
7. Key label format is exactly: space + character + space + reading. Preview combining marks with a dotted circle; insert only the mark. Search displayed characters, Unicode names, readings, and U+ code points. Prefer verified, source-backed readings. Never invent pronunciation: for characters without verified readings, use the bundled descriptive Unicode-name fallback and do not present it as authoritative pronunciation. Document sources, coverage, and limitations.
8. Default to the metallic dark theme; offer light and system themes. Settings includes autosave recovery, theme, text size, font file import, and Use bundled font. Apply and persist changes immediately. Validate imported TTF/OTF files. Keep bundled font licenses and attribution with the app. Keep text-size options/configuration in assets.
9. About: show app icon beside “Avestan Editor”; version 1.0 below; copyright `Copyright (c) 2026 @ArdeshirV, Licenced under GPLv3+`; project URL `https://github.com/ArdeshirV/SummerAvestanEditor`. Keep requested values unlabelled. Support Close, Escape, Return, and keypad Enter.
10. Persist splitter size; default keyboard height to 70%. Keep configurable strings and values in assets. Current app icons are `img/Icon.png` and `img/Icon.ico`; update all resource, build, packaging, and documentation references when paths change.
11. Keep English and Persian READMEs consistent with app behavior. Document supported builds, encoding, settings, shortcuts, readings, licenses, and platform/toolchain requirements.
12. Use architecture-appropriate Qt kits and toolchains for cross-builds. Verify actual binary architecture before naming/copying release artifacts; never label a host binary as another OS or architecture. Android APK packaging must stage the ABI library and locate the APK reliably. Report missing SDK/NDK/JDK/Qt tools honestly.
13. Add/update focused regression tests for document encodings, editing/caret insertion, RTL behavior, keyboard labels/search, settings, and resources. Run `bash tests/run-tests.sh`, validate JSON, and build when possible. Report failures and environmental blockers accurately.
14. Make small, precise changes. Preserve unrelated worktree changes. Do not claim behavior or test results that were not verified.
